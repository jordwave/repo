⚡ Electrum-KMD — Lightweight Wallet for Komodo
==============================================

Electrum-KMD provides a fast, secure, and easy-to-use wallet solution for managing your **Komodo (KMD)** coins. Based on the reliable Electrum platform, it supports hardware wallets and operates smoothly on all major desktop OS.

* * *

### Key Features

* No need to download the full blockchain
    
* Hardware wallet compatibility for added security
    
* Supports Windows, macOS, and Linux
    
* Open-source and community backed
